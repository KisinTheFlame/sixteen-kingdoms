# 长期开发约束

1. 不把“统一中国”写成所有政权唯一合理的玩法终点。
2. 不把传统十六国名单误当作同时存在、边界稳定的国家清单。
3. 区分政治身份、族群称谓、籍贯、部落归属与现代民族概念。
4. 政权强弱必须有财政、人口、军事组织和政治联盟的可解释来源。
5. 东晋内部政治不能只用一个中央集权国家色块概括。
6. 迁徙、坞堡、流民与军镇应影响地图和国家能力，而不只是事件文本。
7. 史料存在分歧时记录采用口径与可信度，不悄然选定唯一叙述。
8. 新机制先做最小可玩版本，再决定是否需要复杂界面。
9. 玩家可见内容全部使用本地化键，术语在文档和游戏中保持一致。
10. 生成数据保留权威来源，避免手改产物造成文档、地图和脚本漂移。
11. 史实通过条件、动机和 AI 权重形成强吸引，不按固定日期强制唯一结果。
12. 玩家成功改变高概率历史走向时，同时提供即时、制度和叙事反馈；任务树是制度反馈的重要载体。
13. 国家分裂时可以连续提供转国选择，但每次只在玩家当前国家与其直接产生的新国家之间转移视角。
14. 改写历史所需的投入与成功收益相称；高难度路线应打开新的生存空间和制度能力，而不是只奖励更大的通用数值。
15. 地图是中国及有限周边构成的完整游戏世界，不保留与四世纪战役并置的原版全球区域。
16. 地图一般以州对应次大陆、郡对应 area、县对应省份；特别小的县只能作为逐案论证的合并特例。
17. 439 年是首轮风味内容视界而非硬终点；此后的通用系统必须允许战役继续，但不承诺同等密度的专属内容。
18. 地图州郡县以约 384 年行政区划作为固定地理基准；游戏中的废置、侨置和辖境变化不要求动态改写地图层级。
19. 任务树用阶段深度和关键分支表达成果，普通任务数量不能替代国家存续、重建或逆转所需的关键状态。
