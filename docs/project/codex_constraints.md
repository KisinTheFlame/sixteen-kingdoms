# 长期开发约束

1. 不把“统一中国”写成所有政权唯一合理的玩法终点。
2. 不把传统十六国名单误当作同时存在、边界稳定的国家清单。
3. 区分政治身份、族群称谓、籍贯、部落归属与现代民族概念。
4. 政权强弱必须有财政、人口、军事组织和政治联盟的可解释来源。
5. 东晋内部政治不能只用一个中央集权国家色块概括。
6. 迁徙、坞堡、流民与军镇应影响地图和国家能力，而不只是事件文本。
7. 史料存在分歧时记录采用口径与可信度，不悄然选定唯一叙述。
8. 新机制先做最小可玩版本，再决定是否需要复杂界面。
9. 玩家可见内容全部使用本地化键，术语在文档和游戏中保持一致。
10. 生成数据保留权威来源，避免手改产物造成文档、地图和脚本漂移。
