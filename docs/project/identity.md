# 项目定位与设计边界

## 核心目标

《东晋十六国》希望把这一时期表现为持续变化的政治生态，而不是一张等待单一王朝统一的碎片地图。

重点议题包括：

- 北方政权的建立、迁徙、联盟、分裂与制度化；
- 东晋朝廷、门阀、宗室、州镇和流民集团之间的权力关系；
- 汉、匈奴、鲜卑、羯、氐、羌等身份在政治组织中的形成与变化；
- 正统、官号、礼制与都城如何转化为可争夺的政治资源；
- 战争、人口迁移和地方治理如何共同重塑南北格局。

## 当前边界

- 游戏平台暂定为 EU4 1.37.x，最终兼容版本须经实际启动确认。
- “十六国”是时代入口，不预设只实现传统十六国名单。
- 项目不在骨架阶段承诺某个唯一开局日期或地图重绘方案。
- 历史人物、地名和族群术语必须先建立资料口径，再进入批量数据。
