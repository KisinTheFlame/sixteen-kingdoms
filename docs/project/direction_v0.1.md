# 项目大方向 v0.1

状态：已确认的大方向基线；书签最终选择与地图边界仍待策划组专项讨论。

## 项目定位

《东晋十六国》是 EU4 的历史全转换模组。玩家控制一个具有明确史实身份的国家，在强烈但不强制的历史压力下经营、生存和改变历史；模组不追求按日期复演唯一结果，也不把所有国家的目标简化为统一中国。

## 历史与玩家能动性

- 史实通过开局条件、人物与集团动机、地方局势和 AI 权重形成强吸引。
- 玩家可以通过可理解且有成本的行动改变高概率历史走向。
- 改史成功同时提供即时收益、制度路线和叙事承认，任务树是主要反馈载体。
- 国家分裂并产生新国家时，可以通过事件让玩家选择留在原国家或转玩新国家；具体释放条件、疆界和危机界面后续设计。

## 时间范围

- 首发书签当前倾向采用代表性的游戏日期 `384-01-01`，但仍待策划组确认。
- `304 年末` 保留为首发备选或未来第二书签。
- 首轮专属历史与风味内容计划做到 439 年左右。
- 439 年不是战役硬终点；玩家可以依靠通用机制继续游戏，南北朝专属内容属于未来扩展。

## 地图方向

- 重建 EU4 整张地图画布，把完整游戏世界限定在中国及有直接联系的有限周边。
- 一般采用“州对应 `superregion`、郡对应 `area`、县对应省份”的层级。
- 特别小的县只能逐案决定是否合并，不批量牺牲县级精度。
- 静态州郡县分组以约 384 年的行政区划为主要参考；后续行政变化不要求动态改写地图层级。
- 先冻结完整画布、投影和顶层结构，再制作一个县级地图垂直切片；验证尺度、性能和玩法后推广到全图。

## 内容结构

- 事件、灾难和通用机制负责施加历史压力。
- 任务树负责展示玩家可以建立的解决方案，并以阶段深度和关键分支表达成果。
- 任务完成得越深入，国家可以从存续走向重建乃至逆转历史；具体国家任务和危机机制不在本轮大方向讨论中冻结。
