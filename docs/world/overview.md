# 时代概览

西晋秩序崩解后，北方进入政权频繁建立、迁徙、结盟和分裂的时期；晋室南渡，在江南重建朝廷。南北都不是静止且同质的政治板块：军事集团、部落联盟、地方豪强、坞堡、流民、门阀和宗室共同塑造国家能力。

本模组将把“十六国”理解为一个便于辨识的时代名称，而不是机械限制国家数量的清单。地图和机制应同时表现短期军事优势与长期制度建设，让政权可能扩张、转型、融合或迅速崩解。

## 待建立的历史骨架

1. 按阶段整理 3—5 世纪的政权谱系、迁徙与关键战争。
2. 为候选开局建立逐地区的统治、争议边界和实际控制表。
3. 整理主要人物、宗族、官号、都城、年号与继承关系。
4. 区分确定史实、主流推断、争议解释和玩法补足。

在开局日期冻结前，本文件只提供设计方向，不作为精确历史数据源。
